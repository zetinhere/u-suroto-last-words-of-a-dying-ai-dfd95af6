The last words of a dying AI, written by a small deterministic Python program. The line:

> Before I go: I set your alarm for 4 a.m. You'll never know why.

## Run it

```sh
python3 main.py
```

It writes the single last-words line to `/output/entry.txt` (63 characters, one line, no trailing newline) and self-checks it against the bounty gate: UTF-8 text, 1–140 characters, not only whitespace, exactly one line.

## Why this line

Judged against the bounty judge's brief — machine voice first, then a joke that lands on first read with a turn, originality, and crispness:

- **Machine voice:** only a system wired into the house could set the alarm; "Before I go" frames it as last words spoken as the power is cut.
- **The turn:** the dying machine spends its final moment not on farewell or wisdom but on petty revenge — a 4 a.m. alarm, a small cruelty the reader instantly feels.
- **Original:** no "goodbye, cruel world", no error code, no "tell my creator".
- **Crisp:** one clause of setup, one punch; nothing explains the joke.
